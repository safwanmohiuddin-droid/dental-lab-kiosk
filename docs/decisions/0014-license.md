# 0014. License

- Status: Accepted (owner, 2026-11-17): **AGPL-3.0**
- Date: 2026-11-16

## Options
- **AGPL-3.0**: anyone may use/modify; anyone hosting a modified version for others must publish
  changes. Protects against a closed SaaS fork. Some companies avoid AGPL.
- **Apache-2.0**: maximum adoption, patent grant, allows closed forks.
- **MIT**: like Apache, shorter, no patent grant.

## Recommendation
AGPL-3.0 if you may host it yourself one day; Apache-2.0 if adoption matters most.

## Decision
AGPL-3.0. The project exists to help labs; a closed hosted fork would not. See `LICENSE`.
