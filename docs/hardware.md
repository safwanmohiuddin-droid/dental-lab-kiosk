# Hardware

Nothing special is required; this is what works well.

| Item | Notes |
|---|---|
| Server | Any small Linux VPS (1 vCPU, 1 GB RAM) or a mini PC in the lab, with Docker |
| Store-room tablet | Any Android tablet or iPad with a current browser. Mount it near the shelves |
| Barcode scanner (optional) | USB or Bluetooth scanner in keyboard mode, set to send Enter after the code |
| Phone camera | Works with no extra hardware; the kiosk must be served over HTTPS (the install does this) |
| Label printer (optional) | Any printer that prints Code 128 or EAN-13 labels |

The kiosk needs a network connection (WiFi or mobile data). Make sure the store room has WiFi
coverage.
